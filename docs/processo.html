A ideia e o repositório

O projeto começou com a escolha do tema: um jogo educativo de geografia. O jogador vê a foto de um monumento brasileiro e precisa clicar no estado onde ele fica.

O repositório foi criado no GitHub para guardar o código e o histórico de cada mudança.

  • Linguagem: C.
  • Biblioteca gráfica: Allegro 5, instalada pelo NuGet no Visual Studio.
  • Conteúdo: estados, regiões e patrimônio cultural do Brasil.
// a regra do jogo em pseudocódigo
mostrar(foto_do_monumento);
esperar(clique_no_mapa);
if (estado_clicado == resposta) {
    pontos += 10;
}

A regra do jogo resumida em pseudocódigo. Todo o resto do código serve para desenhar isso na tela e ler o mouse.

326/10/2026 · 6b9dc8a

Mapa no formato do Brasil

Os retângulos foram trocados por uma matriz de letras com 46 linhas e 47 colunas. Cada letra é um estado e o ponto é o mar. Na tela, cada letra vira um quadradinho de 8 pixels.

As fronteiras são desenhadas onde a letra do vizinho é diferente. O Distrito Federal e Sergipe foram um pouco aumentados para dar para clicar.

// U = SP   V = MG   Y = RJ   . = mar
"OOUUUUUUUVVVVYYY.......",
"OXXUUUUUUVUYYY.........",

Para saber qual estado foi clicado, a posição do mouse é dividida pelo tamanho do quadradinho. Como é uma divisão entre inteiros, o resultado já é a linha e a coluna da matriz.

int coluna = (x - MAPA_X) / CELULA;
int linha  = (y - MAPA_Y) / CELULA;
return estado_da_letra(mapa[linha][coluna]);
426/10/2026 · 6a86420

Menu, tutorial e créditos

O jogo ganhou uma tela de entrada com os botões Jogar, Como jogar e Créditos. Cada tela tem um número com nome, e a variável tela guarda em qual delas o jogador está.

A cada volta do laço principal, um if / else if olha essa variável e desenha só a tela atual. Para trocar de tela, basta mudar o valor.

#define TELA_MENU     0
#define TELA_TUTORIAL 1
#define TELA_CREDITOS 2
#define TELA_JOGO     3
#define TELA_FIM      4

tela = TELA_CREDITOS; // troca de tela

Os botões são retângulos. A função mouse_dentro diz se o mouse está em cima de um deles, e o mesmo teste serve para deixar o botão verde e para aceitar o clique.

606/11/2026 · fd7471d

15 fases e chefes finais

O jogo passou de 3 para 15 perguntas, com monumentos de todas as regiões, do Elevador Lacerda à Ópera de Arame. Cada foto foi recortada no tamanho 300 × 360 pixels.

As duas últimas perguntas viraram chefes finais: o Forte dos Reis Magos e o Real Forte Príncipe da Beira. Neles:

  • o acerto vale 30 pontos em vez de 10;
  • a tecla D não mostra dica;
  • o mapa não acende quando o mouse passa por cima;
  • a foto ganha moldura vermelha.

Tudo isso depende de uma função pequena, usada em cada um desses lugares:

#define PRIMEIRO_CHEFE 13

int eh_chefe(int p)
{
    return p >= PRIMEIRO_CHEFE;
}

A tela final também mudou: os 15 resultados aparecem em duas colunas, usando p / 8 para a coluna e p % 8 para a linha.

Como o jogo funciona por dentro

O jogo inteiro é um laço while que repete três passos até o jogador fechar a janela.

  1. Desenha

    Olha a variável tela e desenha só a tela atual: menu, tutorial, créditos, pergunta ou tela final.

  2. Espera

    al_wait_for_event fica parado até o jogador apertar uma tecla, mexer ou clicar o mouse.

  3. Reage

    Um if / else if decide o que fazer: trocar de tela, mostrar a dica, conferir a resposta ou ir para a próxima pergunta.

Depois do passo 3, o laço volta para o passo 1 e desenha a tela de novo, já com as mudanças.
